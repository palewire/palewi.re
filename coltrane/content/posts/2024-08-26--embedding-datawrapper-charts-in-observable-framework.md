<p>I’ve released another nerdy Reuters trick into the wild.</p>

<p>Here’s <a href="https://observablehq.observablehq.cloud/framework-example-datawrapper-api/">how you can easily integrate Datawrapper charts into Framework</a>, Observable’s slick new dashboarding tool.</p>

<p>You’ll also see how we use Framework’s innovative “data loaders” to generate and embed fresh charts on the fly.</p>

<p>Notice that we’re loading the charts using “web components,” which results in a much snappier user experience than traditional <code>&lt;iframe&gt;</code> tags.</p>

<p>Everyone publishing with Datawrapper should consider doing this. You can learn more <a href="https://www.datawrapper.de/blog/web-component-embedding">about web component embedding</a>.</p>
