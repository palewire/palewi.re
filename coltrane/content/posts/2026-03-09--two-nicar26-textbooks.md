<p>I'm happy to release free, online textbooks covering the two courses I taught at the NICAR26 data journalism conference put on by Investigative Reporters and Editors last week in Indianapolis.</p>

<p>Everything we did in class is scripted out with setup instructions, code snippets and screenshots.</p>

<p><strong><a href="https://palewi.re/docs/first-llm-classifier/">First LLM Classifier</a></strong>, taught with Andrew Briz, will show you how journalists use large-language models to organize and analyze mammoth datasets.</p>

<p>Our script will teach you how to submit dozens of prompts at once as part of an automated routine, and then evaluate and improve results using a rigorous, scientific approach. This year's edition is a significant improvement over last year's experimental run.</p>

<p>You can find it at <a href="https://palewi.re/docs/first-llm-classifier/">https://palewi.re/docs/first-llm-classifier/</a>.</p>

<p><strong><a href="https://palewi.re/docs/first-pmtiles-map/">First PMTiles Map</a></strong>, taught with Jon Schleuss, will show how to display a massive dataset on an interactive map using Protomaps and MapLibre.</p>

<p>It will teach you how to convert heavy shapefiles to the compact PMTiles format, and then display the tiles on an interactive map using a data-driven style. We had a fun debut at the conference, and I'm excited to hear what people think of this technique.</p>

<p>You can find it at <a href="https://palewi.re/docs/first-pmtiles-map/">https://palewi.re/docs/first-pmtiles-map/</a>.</p>
