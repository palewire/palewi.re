<p>AI tricks* aside, Observable's Framework is the most helpful technique I've learned this year. We're using it to publish private dashboards inside the Reuters newsroom.</p>

<p>I created a <a href="https://github.com/palewire/observable-framework-cpi-example">tutorial on deploying similar static sites</a>, for free, via GitHub Pages. You can find all of the code and a step-by-step walkthrough there.</p>

<p>My demonstration case recreates the main elements of the Bureau of Labor Statistics' latest Consumer Price Index press release. The data come from my open-source Python library, cpi, which I've updated with the figures released this week. As a bonus, the code repository also shows you how to calculate the headline inflation rates from scratch.</p>
