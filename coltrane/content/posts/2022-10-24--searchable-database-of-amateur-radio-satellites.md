<p>My first ham radio project is out.</p>

<p>I'm happy to have partnered with Mineo Wakita (JE9PEL) to create a searchable, sortable database of all the amateur radio satellites in space.</p>

<p>It's now live on the <a href="https://amsat.org/amateur-satellite-index">AMSAT website</a>.</p>

<p>It will live update by drawing data from this new <a href="https://github.com/palewire/amateur-satellite-database">GitHub repository</a>, which uses automated actions to mirror Mineo's curated list and merge it with the SatNOGS registry.</p>

<p>The frontend code that runs the website is available on <a href="https://gitlab.amsat.org/open-source/amsat-satellite-index">AMSAT's GitLab instance</a>.</p>

<p>I'm told it's the first AMSAT web application created by external developers via open-source techniques.</p>

<p>Shout-out to Matthew Alberti on the AMSAT IT team for trusting the weird web-hosting tricks I've learned crashing dozens of news apps.</p>

<p>Shout-out to Mineo Wakita for providing machine-readable data, and for never changing his fly 90s-style <a href="http://www.ne.jp/asahi/hamradio/je9pel/">web design</a>.</p>
