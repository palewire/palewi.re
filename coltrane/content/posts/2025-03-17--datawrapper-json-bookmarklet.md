<p>I'm happy to release a new open-source bookmarklet that quickly jumps to the JSON configuration of any Datawrapper chart.</p>

<p>You can learn how to install and use the tool by visiting <a href="https://palewi.re/docs/datawrapper-json-bookmarklet/">our documentation</a>.</p>

<p>Here's why we made it.</p>

<p>Our Reuters team spends a lot of time working with the Datawrapper API, a web service that empowers us to automate the creation of hundreds of newsmaking charts each week.</p>

<p>However, when we're developing a new chart template, it's not always obvious which backend setting corresponds to which frontend feature.</p>

<p>We've found that reviewing the configuration options generated by the site's point-and-click interface can help us better understand how a chart is assembled -- and how it can be automated.</p>

<p>This bookmarklet speeds up the process by directly jumping from a chart's editing panel to the URL that hosts its configuration in JSON format.</p>

<p>We hope it can help others do the same.</p>
